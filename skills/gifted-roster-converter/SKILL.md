# 資優鑑定成績轉檔

把學校的成績輸入檔轉成報名系統的匯入檔。**不照抄學校篩好的名單**：從段考原始分數重算百分等級，再和學校名單逐筆對照。學校篩錯時，照抄只會跟著錯，而且看不出來。

規則的來源、百分等級公式和已知的壓線情況，都寫在 `references/rules.md`。使用者問「為什麼這個人有／沒有」時，先讀那份檔案再回答。

## 步驟

1. **確認三個參數**。使用者沒講就用預設，並在回報時寫出用了哪些值：
   - 學年度（預設 115）。簡章標題是 115 學年度，但報名系統的範本範例寫 116，**以承辦或報名系統的要求為準**。使用者不確定時，提醒對方去確認，不要自己猜。
   - 一般生門檻 93、特殊身分門檻 85（依基隆市 115 學年度簡章）。換縣市或換年度時，請使用者提供新簡章的門檻。

2. **執行轉檔**（需要 Python 3 和 `pandas`、`openpyxl`；沒有的話先 `pip install pandas openpyxl`）：

   ```bash
   python scripts/convert.py "<成績輸入檔路徑>" --year 115 --pr-general 93 --pr-special 85 --out-dir "<輸出資料夾>"
   ```

   - 可以一次給多個檔案。加 `--json` 會輸出結構化報告，方便你逐項讀取。
   - 輸出檔名是 `已轉檔_<原檔名>.xlsx`，工作表名稱是 `薦送名單`。
   - 結束代碼 0＝全部成功；1＝有檔案拒絕轉檔（例如少一科的成績表），原因寫在報告裡。

3. **照實回報**，不要改寫或省略：
   - 每一科的全年級人數、符合人數（一般／特殊身分），以及學校名單是否一致。
   - 「⚠️ 請人工確認」底下的**每一條**。這些就是承辦要處理的事，不能只說「有幾個小問題」。
   - 拒絕轉檔的檔案和原因。**不要為了產出檔案去改原始檔，或繞過檢查。**
   - 固定提醒：「學校代碼」「學號」兩欄原始檔沒有資料，要自行補上。

4. **使用者問到壓線、缺考或算法時**，讀 `references/rules.md` 的「已知壓線情況」回答。不要自己發明新的算法。

## 不要做的事

- 不要改用「照抄學校薦送名單」的做法，就算算出來和學校一樣也不要。
- 不要自行更改門檻或百分等級公式；使用者明確指示時才改，而且要在回報裡寫清楚。
- 這是學生個資，含姓名和經濟、身心障礙等身分：
  - 不要把原始檔或名單上傳到使用者沒指定的外部服務。
  - 不要把學生全名寫進進度紀錄、筆記或給其他 agent 讀的檔案；需要舉例時用「某位中低收入學生」這種寫法。
- 原始檔不符合預期格式時（找不到「學生姓名」表頭、沒有「段考」欄、少一科），回報錯誤並請使用者確認檔案，不要猜欄位。

## 原始檔格式（腳本預期）

- 每科一張「PR計算」工作表，名稱含科目關鍵字和「PR」，例如 `國文PR計算`、`自然科學PR計算`；前後多空格沒關係。
  - 科目關鍵字：國文／國語、英語／英文、數學、自然／生物／理化。
- 表頭列要有「學生姓名」，可以不在第一列（會在前 20 列裡自動找）。建議也有「班級」「座號」「特殊身分標記」「Pr值」。
- 段考分數欄的名稱以「段考」開頭，例如段考一、段考二、段考三。
- 每科最好還有一張「薦送名單」工作表（名稱含科目和「薦送」），讓腳本可以核對學校的名單；沒有的話只會在報告裡註明。
